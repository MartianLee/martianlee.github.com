## 구성 (본문 6절)

0. **도입** — 1편과의 연결 인용구 + 전이 의존성 프레임 한 문단.
1. **하루를 따라가 봅니다** — 모델 시나리오 소개 + **V1** + 두 문단(점심이 70%라는 순서의 놀라움, 1인당 평균과 경계가 다르다는 주의).
2. **먹는 것** — 도입 1문단 + **V2** + 메탄이 차이를 만든다는 1문단.
3. **이동** — passenger-km 단위 설명 1문단 + **V3** + 전기차 배출은 전력망이 정한다는 1문단.
4. **물건** — 제조 단계가 대부분이라는 1문단(휴대폰) + **V4** + 티셔츠의 연구별 편차(3편 예고) + 수명이 지렛대라는 1문단.
5. **전기 한 칸의 뒷면** — kWh는 에너지 단위일 뿐이라는 1문단 + **V5** + 지렛대 길이가 다르다는 1문단.
6. **그래서 어디에 힘을 쓸 것인가** — 단가 × 횟수, 개인 대 시스템, 3편(LCA) 예고. 시각화 없음.
7. **출처와 수치 검증** — 출처 목록 + 기준 연도 + 하루 시나리오의 계산식과 가정 전부 공개.

## 시각화 5개

| ID  | 컴포넌트        | 내용                        | 형태                                                                                                             |
| --- | --------------- | --------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| V1  | `CarbonDay`     | 하루 항목별 누적 배출       | 24시간 트랙 위를 카메라가 이동, 사건마다 부피 비례 CO₂ 큐브가 누적. 라벨은 HTML 오버레이(TonneCubes 방식 재사용) |
| V2  | `FoodMasses`    | 식품 1kg당 배출             | 접시 위 CO₂ 부피 큐브, 채소에서 소고기로 패닝하며 스케일이 무너지는 순간                                         |
| V3  | `TravelLanes`   | 1인 1km당 배출              | 수단별 레인, 뒤로 남기는 입자 꼬리 길이 ∝ g/km (`makePoints`/`discSprite` 재사용)                                |
| V4  | `EmbodiedGoods` | 물건 1개의 생애 배출        | 물건은 실제 크기, 그 위에 제조 배출 부피 구름. 크기와 구름이 비례하지 않는 것이 요지. 단계별 비중은 오버레이     |
| V5  | `GridTiles`     | 같은 사용량, 다른 전력 계수 | 연간 kWh 타일 격자 + 배출 기둥, 전력 믹스를 바꾸면 기둥만 낮아짐                                                 |

- 장면 수는 5개가 기본값(저자 승인). 축소가 필요하면 V5를 막대 비교로 강등하는 것이 1순위.

## 수치

검증 완료(2026-09-10). 확정치와 출처는 `data/charts/carbon-basics-2.ts`에 주석과 함께 고정했습니다. 초안 대비 바뀐 것:

- 한국 전력 계수 0.4594(2011) → **0.4173**(2023, 소비단). 국가 비교는 연도·출처를 통일하려고 Ember 2024를 따로 쓰므로 한국 값이 두 개가 됩니다. 본문 각주로 이유를 밝힙니다.
- 오토바이 103 → **113.6 g**(103은 출처 없음). 기관명은 DEFRA/BEIS가 아니라 **DESNZ**(2022년 계수).
- 스마트폰 56 → **55 kg**(iPhone 17 256GB), 단계 비중 제조 77 / 사용 18 / 수송 4.
- 노트북 약 150 → **145 kg**(MacBook Air 15" M5 512GB), 제조 63 / 사용 27 / 수송 10.
- 티셔츠 2.1(출처 불명) → **8.4 kg**(세탁 56회 포함). 경계 이야기용으로 3.4(제조까지)와 15(온수 50회)를 함께 인용합니다.
- 소고기 99.5는 **육우 한정값**이라 라벨에 명시(낙농 부산물 포함 평균은 약 60).
- 국내선 항공 245.9에는 고고도 비-CO₂ 효과가 포함되어 있어 각주 필요.
- **제외**: 택배 라스트마일(연구별 0.1~1.1kg, 편차 10배), 자전거·도보(배기 0이나 식이 기반 16~50g, DEFRA 차트 미포함).
- 휘발유차 4인 분담 42.6g은 OWID 발행값이 아니라 170.5÷4 **자체 계산**이므로 라벨에 표기.
- 가구 전력은 통계가 아니라 **가정**(월 300kWh = 연 3,600kWh, 주택용 누진 2단계 구간).
- 하루 시나리오 합계 **20.13 kg**, 그중 점심 한 끼가 74%.

### 물건 막대는 제조/사용을 쪼갠다

청바지 33.4kg은 세탁 포함, 티셔츠 저가값은 제조까지라 한 축에 그냥 놓으면 경계가 다른 값을 비교하게 됩니다. 그래서 막대를 제조·수송 / 사용으로 나눕니다. 전자기기는 제조가 대부분이고 옷은 사용(세탁)이 절반이라는 대비가 그대로 드러나며, 개인의 지렛대도 "오래 쓰기"와 "덜 빨고 찬물로 빨기"로 갈립니다.
