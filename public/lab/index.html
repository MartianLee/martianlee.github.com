홈 화면 시안 3종

홈 비주얼 시안 3종을 보관하는 실험실 페이지입니다. A(Red Horizon)를 채택해 사이트에 적용하고 있고, B와 C는 이곳에서 원본 그대로 동작합니다. 검색엔진 색인을 막아 두었고 사이트 어디에도 링크하지 않았습니다. 시안 화면 아래쪽 바에서 A, B, C를 오가고 라이트와 다크를 바꿔 볼 수 있습니다.

  • 01모션 그래픽히어로마다 실시간으로 렌더링되는 장면이 하나씩 있습니다. 셰이더 풍경, 점균 시뮬레이션, 벡터 빔입니다.
  • 02화려함화려함은 히어로 한 곳에 모으고, 아래 섹션은 같은 시각 언어로 절제했습니다.
  • 03빠른 첫 로딩페이지 하나가 gzip 17.5~21.5 KB이고 이미지는 0장입니다. 글자를 먼저 그리고 캔버스는 첫 페인트 뒤에 켭니다.
  • 04AI인 걸 알아도 “와”흔한 효과 대신 이 블로그에만 있는 재료로 만들었습니다. 이름의 Martian, 실제 노트 108개와 링크, 2017년부터 쌓인 글쓰기 기록입니다.

무엇이 움직이나
셰이더 하나가 화성의 사구와 메사를 실시간으로 그립니다. 진짜 HTML 제목(MARTIAN LEE.)이 하늘과 지형 사이에 끼어 있어서, 먼 메사가 글자 아랫부분을 묻고 대기의 먼지가 글자를 흐리게 덮습니다. 카메라는 천천히 전진하고 포인터를 따라 시차가 생깁니다.
“와” 포인트
라이트는 화성의 오후, 다크는 화성의 일몰입니다. 화성의 일몰이 파랗게 보이는 건 실제 현상이고, 해는 MARTIAN과 LEE 사이 골짜기로 집니다. 테마를 바꾸면 해가 하늘을 가로질러 움직입니다. 오른쪽 아래 계기판은 제제로 크레이터의 현지 시각, 화성년과 계절, 지구에서 화성까지 빛이 닿는 시간(지금 13분 18초)을 실시간으로 계산합니다.
트레이드오프
GPU 부하가 셋 중 가장 큽니다. 렌더 해상도를 0.75배에서 시작해 프레임이 밀리면 자동으로 낮춥니다. 브랜드(종이, 잉크, 러스트, Newsreader)는 가장 많이 유지하고 제목 서체만 Archivo 확장형으로 바꿨습니다.

A · Red Horizon (채택)

2026년 10월 10일, A를 지식 베이스를 뺀 사이트 전체에 적용하기로 했습니다.

B의 점균 네트워크와 C의 벡터 빔은 시각적인 힘이 커서 이곳에 원본 그대로 남겨 둡니다. C의 경력 막대는 새 홈의 경력 섹션으로 가져갑니다.

크기는 HTML 파일 하나(마크업, CSS, JS)를 gzip -9로 잰 값입니다. 웹폰트는 별도로 받으며, 실제 블로그에서는 next/font로 셀프 호스팅됩니다.

시안 하단 바의 FCP와 fps는 지금 보고 있는 기기에서 실시간으로 잰 값입니다. 이 보드의 스크린샷은 헤드리스 크롬의 소프트웨어 렌더러로 찍었습니다.

비교용 수치: 지금 라이브 홈은 첫 방문에 이미지 7장(746 KB), JS 311 KB, 웹폰트 182 KB를 받습니다(전송량, 헤드리스 크롬 1회 측정). 시안의 프로젝트 썸네일은 이미지 대신 코드로 그린 타일입니다. 실제 스크린샷을 쓰려면 지연 로딩으로 붙이면 됩니다.
